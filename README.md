# Heogangchan

This project contains a static web app and supporting data/assets files.

## Structure

- `index.html` — main page
- `assets/` — styles, scripts, and static frontend assets
- `data/` — course/content data files
- `tools/` — utility scripts

## Run locally

Open `index.html` in a browser, or serve the directory with a small local HTTP server.

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.
